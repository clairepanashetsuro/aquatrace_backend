Title: Limits and standards
Source: AquaTrace project reference list (sample)
Version: 1

Reference values used by AquaTrace.
- pH 6.5 to 8.5 [UNVERIFIED]
- Turbidity 5 NTU upper reference [UNVERIFIED]
- Electrical conductivity 1500 µS/cm upper reference [UNVERIFIED]
- Temperature 12 to 25 °C [PROJECT CHOICE]
AquaTrace does not measure microbes or chlorine.
